# Global Codex working agreements

For every repository: locate the project's AGENTS.md and any nested instructions.
Inspect the current source of truth and the current working tree before editing.
Keep observations, hypotheses, proposed decisions and approved requirements
separate. Preserve the request's original objective through every interruption.
For nontrivial changes, capture objective, impact, plan, actual command results,
risks, decisions, and a final reproducible handoff in the repository. Do not
claim tests, merges, external actions or owner approval without evidence.
Never write credentials or private data to source or logging artifacts.
Ask for authorization before external publication, destructive data actions,
unapproved spending, or scope changes; don't ask again for already authorized
reversible work. Follow the project's executable gates and the user's instructions.
